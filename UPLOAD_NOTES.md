# Upload Notes

This directory is the recommended low-risk public release shape for PEG-Bench.

Recommended hosting wording:
"PEG-Bench is a benchmark protocol and executable evaluation artifact over licensed third-party market data. We release the evaluator, splits, schemas, execution contract, normalized evidence, result reproduction scripts, and inspection/sample artifacts. Full raw-data reconstruction requires authorized access to the underlying market-data provider."

If publishing on Hugging Face, use this public-safe release rather than the larger internal processed-data package.
