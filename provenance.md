# Provenance

PEG-Bench is built over licensed third-party market data. The public-safe release excludes both raw feeds and the fully reconstructed benchmark-ready arrays derived from them.

Included here are only:
- benchmark protocol manifests
- normalized result evidence
- reproduction scripts
- generated tables and supplemental bundles

Underlying raw-data reconstruction requires separately authorized access to the original market-data provider and any applicable venue/vendor terms.
